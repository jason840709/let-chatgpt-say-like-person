# 讓 ChatGPT 正常說人話

讓 AI 用自然中文把事情講清楚：讀者知道你在說什麼、為什麼這樣判斷，以及建議怎麼做。

這份 skill 主要用於中文，規則與範例以**臺灣繁體中文**為主。作者平常也主要在中文情境使用與調整；**英文沒有充分測試**，使用英文時請自行確認語氣與表達是否合適。目前版本為 **v2.4.2**。

## 它會處理什麼問題？

有些 AI 回答看起來很完整，讀完卻仍不知道它在說什麼。可能是術語沒有解釋、用「前者」「原本那套」省掉重要對象，或只說「建議先等」，卻沒說等待的理由。也常見每段都加連接詞、同一件事換句話說好幾次，以及用一串免責把結論淹沒。

這份 skill 要求 AI 保留理解所需的資訊，把多餘的文字刪掉。句子可以長一點，只要增加的文字能說清楚對象、因果或決策條件。研究與技術文件還要交代數字從哪裡來、比較的是誰，以及證據支持到什麼程度。

適合用來寫或修改中文對話回答、說明文件、研究報告、技術分析、論文草稿與決策建議。

## 它怎麼讓 AI「說人話」？

`SKILL.md` 是給 AI 讀取的完整指令。AI 依照指令整理材料、撰寫內容，再檢查並修改初稿。整套寫作與審閱規則都放在同一個檔案裡。

1. **先確認讀者知道什麼。** 把讀者不熟悉的術語與操作放在第一次需要的位置解釋，讓讀者能順著文章讀下去。
2. **先回答問題，再說理由。** 建議要交代值得這樣做的原因；會改變建議的條件也要說清楚。改寫時核對來源、時間、判斷方式及負責行動的人，避免把原本的意思改掉。
3. **把省掉的對象補回來。** 例如把「沿用前者」改成真正的方法名稱；把「設定不同」展開成實際不同的項目。
4. **讓數字有意思。** 比例交代分子與分母，指標交代衡量對象與方向，比較交代基準。涉及研究分析時，再檢查樣本單位、統計方法與證據。
5. **刪掉沒有幫助的文字。** 清理翻譯腔、空泛形容詞、模板式開場、鄰近重複，以及沒有實際作用的防禦性用詞。真正影響解讀的限制保留在相關位置。
6. **交付前再讀一遍。** 從理解、方法、統計、重要反例、編輯、結論價值與成品誠信七個面向檢查；方法與統計項目依任務適用性處理。發現缺口就修改，回報只寫實際完成的檢查。

例如「先等」只交代了動作。如果等待的理由與後續安排都在來源材料裡，就應把理由和安排寫出來：

> 建議先等到明早，因為供應商預計今晚更新庫存。明早確認庫存後，再決定是否改買替代產品。

研究文字也要讓讀者看懂數字。以下是假設資料的寫法示例：

> 方法 A 的平均預測誤差為 0.42，基準方法為 0.35；方法 A 的誤差高 0.07。

實際使用時，數字與理由都必須來自當次材料。來源缺少資訊時，AI 應指出具體缺口。

## 怎麼使用？

如果你的 AI 工具支援載入 skill，將本 repository 的資料夾放入工具指定的 skill 目錄，並保留 `SKILL.md` 與資料夾內的檔案。啟用方式依工具而定，skill 名稱是 `jason-let-chatgpt-say-like-person`。

也可以直接把 [SKILL.md](SKILL.md) 的完整內容提供給 AI，再附上任務與原文：

```text
請依照 jason-let-chatgpt-say-like-person 的規則改寫下面的文章。
讀者是沒有參與專案的工程師。
請保留原意、數字、證據強度與必要條件，讓讀者能看懂做法和理由。

［貼上原文］
```

撰寫新文件時，提供資料、讀者與用途會更容易得到合適的內容：

```text
請依照這份 skill，用臺灣繁體中文撰寫技術說明。
讀者是第一次接觸這個專案的同事，目的是讓他知道問題、做法與目前結果。
請以附上的材料為依據；缺少的資訊請具體指出。
```

一般對話也可以使用：

```text
請用這份 skill 回答。先直接回答我的問題，再用完整句子說明理由；
需要的新術語請當場解釋。
```

## 檔案與使用範圍

- [SKILL.md](SKILL.md)：v2.4.2 完整規則，包含寫作、改寫、審閱與交付檢查。
- [agents/openai.yaml](agents/openai.yaml)：原始套件的介面設定，供支援此格式的工具使用。
- [assets/icon.svg](assets/icon.svg)：原始套件的圖示。

skill 的寫作規則可獨立使用。讀取資料、重算數字或檢查 PDF、DOCX、HTML 成品，仍需要 AI 所在環境提供相應工具；能執行哪些檢查，取決於該次任務與工具能力。

本 README 也依照這份 skill 撰寫。這裡說明的是規則與使用方法；目前沒有提供跨模型的量化成效測試。使用後可以檢查：原意是否保留、讀者是否理解對象與理由，以及回答是否仍有套話或重複文字。
