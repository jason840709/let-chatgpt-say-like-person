本次從上一個公開版本 **2.6.0** 更新到 **2.8.1**。2.7.x與2.8.0是中間開發版本，沒有另發公開Release。

這版把常用規則集中到精簡入口，讓AI少讀重複內容，同時補強容易讓人看不懂的地方：

- 說清楚誰做了什麼，先介紹資料區段、指標與模型，再用它們推論；不靠後文替前文補意思。
- 清楚承接同一主語的句子可以保留，不要求每句都加「我們」。
- 保留數字、公式條件、來源和建議／已完成的差別，避免把其他案例或技能安排寫成眼前案件的事實。
- 重要文件先做一次初審，修訂後複核受影響處；需要的補讀與複核不受固定檔數或回合數阻擋。
- 全文順讀與真正逐句供稿分開記錄，歷史測試保留原受測版本。

**相同公開檔案範圍的文字量：**日常入口由15,335縮至8,329 bytes（減少45.7%）；入口加審稿手冊由28,820縮至13,060 bytes（減少54.7%）。這是UTF-8文字量，不是token、費用或帳號額度的實測節省率。

開發時完成12題一次性新舊對照，另有三題入口測試與兩題修正後局部複測。對照基準是2.7.1，而非2.6.0；結果不保證所有文章都更好，也未測完跨模型或各產品自動觸發。詳見[驗證範圍](https://github.com/jason840709/let-chatgpt-say-like-person/blob/v2.8.1/VALIDATION.md)。

**升級方式：**下載完整ZIP，以其中的`let-chatgpt-say-like-person/`資料夾取代舊版，保留`references/`。公開啟用名稱不變，不用修改原有指令。

附件提供完整Skill ZIP、由同版來源產生的離線閱讀頁、檔案清單與SHA-256。下載內容已核對來源與封裝，離線頁已檢查桌面／手機顯示、導航及複製按鈕；剪貼簿以模擬介面測試。
